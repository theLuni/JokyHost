# Условия использования JokyHost

## 1. Общие положения
1.1. Настоящие Условия использования (далее — «Условия») регулируют отношения между Администрацией сервиса JokyHost (далее — «Администрация») и Пользователем при использовании сервиса по предоставлению хостинга для Heroku Userbot (далее — «Сервис»).

1.2. Использование Сервиса означает полное и безоговорочное принятие Пользователем настоящих Условий.

## 2. Услуги и стоимость
2.1. Сервис предоставляет Пользователю виртуальный сервер для размещения Heroku Userbot.

2.2. Стоимость услуг составляет **50 рублей** за 1 календарный месяц использования.

2.3. Оплата производится авансовым платежом за выбранный период (1, 3, 6 или 12 месяцев).

2.4. Сервис активируется только после подтверждения оплаты Администрацией.

## 3. Права и обязанности Пользователя
3.1. Пользователь обязуется:
- Использовать Сервис только в законных целях
- Не нарушать законодательство РФ и международное право
- Не размещать запрещенный контент (порнография, экстремизм, наркотики, оружие, фишинг, спам, DDoS-атаки)
- Не пытаться взломать или нанести ущерб инфраструктуре Сервиса
- Своевременно оплачивать услуги

3.2. Пользователь имеет право:
- Получать доступ к своему серверу 24/7
- Обращаться в поддержку по вопросам работы Сервиса
- Запросить резервную копию данных при прекращении обслуживания

## 4. Права и обязанности Администрации
4.1. Администрация обязуется:
- Обеспечивать работоспособность Сервиса (SLA не менее 99%)
- Уведомлять Пользователя о плановых технических работах
- Хранить данные Пользователя в тайне
- Рассматривать заявки на пополнение баланса в течение 24 часов

4.2. Администрация имеет право:
- Приостановить или прекратить доступ к Сервису при нарушении Условий
- Изменять тарифы с предварительным уведомлением за 7 дней
- Отказать в обслуживании без объяснения причин
- Удалить неактивный сервер по истечении срока оплаты

## 5. Финансовые условия
5.1. Пополнение баланса осуществляется через перевод по СБП на номер **+79270614020** с обязательным прикреплением чека.

5.2. Средства не возвращаются в случаях:
- Нарушения Пользователем настоящих Условий
- Добровольного отказа от услуг до окончания оплаченного периода
- Блокировки сервера по жалобам третьих лиц

5.3. Возврат возможен только при технической невозможности предоставления услуг со стороны Администрации.

## 6. Конфиденциальность
6.1. Администрация собирает и хранит только следующие данные:
- Telegram ID Пользователя
- Имя и username (при наличии)
- История платежей
- Технические логи сервера

6.2. Данные не передаются третьим лицам, кроме случаев, предусмотренных законодательством РФ.

## 7. Ответственность
7.1. Сервис предоставляется «как есть» (AS IS). Администрация не гарантирует:
- Абсолютную безотказность работы
- Совместимость с любыми версиями Userbot'ов
- Сохранность данных при форс-мажорах

7.2. Пользователь самостоятельно несет ответственность за:
- Действия своего Userbot'а
- Сохранность данных на сервере
- Настройку безопасности

7.3. Администрация не возмещает упущенную выгоду или косвенные убытки.

## 8. Блокировка и удаление сервера
8.1. Сервер автоматически блокируется через 3 дня после истечения оплаченного периода.

8.2. Сервер полностью удаляется через 14 дней после истечения оплаченного периода без возможности восстановления.

8.3. Сервер может быть заблокирован немедленно при:
- Получении обоснованной жалобы на действия Userbot'а
- Обнаружении вредоносного кода
- Использовании для атак на другие ресурсы
- Распространении запрещенной информации

## 9. Изменение условий
9.1. Администрация вправе в одностороннем порядке изменять настоящие Условия.

9.2. Изменения вступают в силу через 3 дня после публикации в канале **@LuniDev**.

9.3. Продолжение использования Сервиса после изменений означает согласие с новой редакцией.

- Ознакомился с настоящими Условиями в полном объеме
- Согласен со всеми пунктами без исключений
- Достиг возраста 18 лет (либо имеет разрешение законных представителей)
- Действует добросовестно и в рамках законодательства
